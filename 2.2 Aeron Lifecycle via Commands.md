<h2 id="🔁-生命周期分阶段（核心理解）">🔁 生命周期分阶段（核心理解）</h2>
<hr>
<h3 id="️⃣-建通道（控制路径）">1️⃣ 建通道（控制路径）</h3>
<pre><code>app
  -&gt; addPublication / addSubscription
  -&gt; Client Conductor
  -&gt; Command RingBuffer
  -&gt; Driver Conductor
  -&gt; 创建 Publication / Subscription / LogBuffer / Image
</code></pre>
<p>👉 结果：</p>
<pre><code>资源已创建，但数据流尚未建立
</code></pre>
<hr>
<h3 id="️⃣-激活（连接建立）">2️⃣ 激活（连接建立）</h3>
<pre><code>Driver ↔ Network
  -&gt; Setup Frame
  -&gt; Status Message
  -&gt; 建立 Image / Receiver
</code></pre>
<p>👉 标志：</p>
<pre><code>isConnected = true
</code></pre>
<hr>
<h3 id="️⃣-稳态流（数据路径）">3️⃣ 稳态流（数据路径）</h3>
<pre><code>Producer:
  Publication.offer() -&gt; 写 LogBuffer

Driver:
  Sender   -&gt; 发数据
  Receiver -&gt; 收数据 -&gt; 写 Image LogBuffer

Consumer:
  Subscription.poll() -&gt; handler
</code></pre>
<hr>
<h3 id="️⃣-协议调节（持续发生）">4️⃣ 协议调节（持续发生）</h3>
<pre><code>Receiver -&gt; Status Message（消费进度）
Receiver -&gt; NAK（丢包请求）

→ Driver 调整发送窗口
→ Publication.offer() 可能 BACK_PRESSURED
</code></pre>
<hr>
<h3 id="️⃣-关闭（控制路径）">5️⃣ 关闭（控制路径）</h3>
<pre><code>app -&gt; close()
  -&gt; Client Conductor
  -&gt; Driver Conductor
  -&gt; 释放资源
</code></pre>
<hr>
<h2 id="⚙️-关键分层（必须记住）">⚙️ 关键分层（必须记住）</h2>
<pre><code>控制路径（Command RingBuffer）：
  建 / 改 / 关（低频）

数据路径（LogBuffer）：
  payload 流动（高频）

协议路径（SM / NAK / Flow Control）：
  持续调节数据流
</code></pre>
<hr>
<h2 id="📦-附录：核心命令">📦 附录：核心命令</h2>
<pre><code>ADD_PUBLICATION / REMOVE_PUBLICATION
ADD_SUBSCRIPTION / REMOVE_SUBSCRIPTION
ADD_DESTINATION / REMOVE_DESTINATION
CLIENT_KEEPALIVE
ADD_COUNTER / REMOVE_COUNTER
TERMINATE_DRIVER
</code></pre>
<hr>
<h2 id="🧠-一句话总结（最终版）">🧠 一句话总结（最终版）</h2>
<p>Aeron 通过命令建立通信结构，通过独立的数据路径传输 payload，并依赖协议机制持续调节流量，最终再通过命令释放资源。</p>
